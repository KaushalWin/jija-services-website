# Pilot 1 — Clean Business Catalogue

Static, mobile-first catalogue concept for JIJA Services LLC. No backend, database, cart, checkout, analytics, or user-data collection.

Serve locally with any static file server, for example: `python3 -m http.server 4173 -d pilot-1`.

Product images are crops of the catalogue supplied by the client. Public pack prices are transcribed from the supplied sale flyer; all other products use “Contact for price.” Marketplace buttons are intentionally marked coming soon.
